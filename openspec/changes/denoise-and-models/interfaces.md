## Настройки: поля `SpeechConfig` (заморожено)

Существующий `SpeechConfig` (`src/services/speechSettings.ts`) дополняется ровно этими полями,
Rust-структура настроек — теми же именами:

```ts
denoise_highpass: boolean;        // по умолчанию true
denoise_highpass_hz: number;      // по умолчанию 80
denoise_gate: boolean;            // по умолчанию true
denoise_gate_db: number;          // по умолчанию -45
denoise_rnnoise: boolean;         // по умолчанию false — меняет тембр, включается вручную
denoise_agc: boolean;             // по умолчанию false
denoise_agc_target_db: number;    // по умолчанию -20
```

Цепочка применяется к микрофону **в обоих трактах**: диктовка (`stt/capture.rs`) и запись
(`recording/audio.rs`). Порядок обработки: RNNoise → high-pass → гейт → AGC → дальше как было
(ресемплинг 16 кГц и VAD-обрезка).

- RNNoise (`nnnoiseless`) работает на 48 кГц кадрами по 480 отсчётов; при другой частоте
  устройства — ресемплинг на входе и выходе цепочки, без изменения итоговой частоты тракта.
- Гейт опирается на уже существующий VAD: кадры ниже порога глушатся до нуля, а не удаляются —
  длина записи не меняется.
- AGC выравнивает RMS к цели и не трогает кадры ниже гейта.
