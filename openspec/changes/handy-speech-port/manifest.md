# Manifest: Handy → Tempo speech module

Дословные цитаты пользователя (запрос + ответы виджета Wave 0, 2026-09-22):

- «Проанализируй этот https://github.com/cjpais/handy репо и я хочу чтобы ты детально скопировал и внедрил нам все функции в наш Push to talk TTS модуль»
- «я хочу иметь возможность удобно выибирать и разворачивать локальные модели»
- «зажимать кнопку наговаирвать»
- «scope: Всё как в Handy»
- «catalog: Как в Handy (20+ и кванты)»
- «ui: Расширить вкладку «Speech to Text»»
- «ptt_default: Hold-or-Toggle (как в Handy)»
- «engines: Только Whisper (transcribe-cpp)»

Отклонения, согласованные объёмом (фиксируются честно, а не молча):

| Что | Почему | Потолок | Апгрейд |
|---|---|---|---|
| Silero VAD (ONNX-бэкенд) | `vad-rs` в Handy — git-форк + ONNX Runtime в установщике | Energy + Earshot | добавить `ort`, когда размер установщика перестанет быть ограничением |
| Второй бэкенд клавиатуры (`handy-keys`) | нужен для macOS `fn`-клавиши; у нас Windows и системных хоткеев достаточно | `tauri-plugin-global-shortcut` | `handy-keys`, если понадобится обход системных хоткеев |
| Оверлей отдельным окном | у нас есть мини-оверлей и пилюля; второе окно дублирует их | расширенный индикатор | отдельное окно, если индикатор перестанет помещаться |
| Ручной выбор звука (файл темы) | темы синтезируются программно, внешних ассетов нет | 3 темы (default/soft/mechanical) | файлы тем, если понадобится брендовый звук |
| `mute_while_recording`, `lazy_stream_close`, `always_on_microphone` (раздел Debug у Handy) | отладочные эксперименты Handy: глушат системный звук (вместе с нашим будильником) или держат поток микрофона открытым всегда | аудиовход открывается на запись и закрывается после неё | пересмотреть, если задержка старта станет заметной |
| macOS-специфика Handy (`clamshell microphone`, `Apple Intelligence`, `secure input warning`, `fn`-клавиша, `handy-keys`) | платформа проекта — Windows; в Handy это отдельные ветки кода под macOS | нет | при появлении macOS-сборки |

Уточнения к формулировкам требований (не ослабление, а точный счёт):

- **R04**: «позиция» = карточка модели × квант. Каталог берёт семейство Whisper из каталога Handy
  целиком: **13 моделей × 6 квантов = 76 скачиваемых файлов**, поэтому «20+ и кванты» выполнено
  с запасом; в UI — карточка модели с переключателем кванта перед скачиванием (у Handy выбор
  кванта в UI отсутствует — там всегда берётся `default_quant`).
- **R15/R16 (язык, словарь)**: список языков — тот, что реально принимает transcribe-cpp для
  выбранной модели (`Capabilities::languages`), а не статический список из Handy.
- **R20 (пост-обработка)**: идёт через существующий `ai.rs`/`aiGateway` с ключом из системного
  хранилища — у Handy отдельный экран API-ключей, у нас он уже есть в разделе ИИ.
