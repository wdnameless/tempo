# Proposal: починка дефектов полного QA-прогона

## Почему

Приложение выросло волнами, и проверки нашли то, что накопилось между ними: восемь блокеров,
из которых три объясняют жалобу «функционал не связан с интерфейсом» целиком —
ассистент никогда не вызывает модель (проверяет пустой ключ вместо системного хранилища),
будильники из ассистента звонят не в те дни (разная нумерация дней недели), а кнопка «Стоп»
не останавливает запись. Плюс три блокера потери данных в заметках и один в задачах.

## Что делаем

Семь срезов, файлы разведены по владельцам (`interfaces.md` §1), порядок — по тяжести.

1. **FixAlarmCore** (Rust): отложенный будильник, двойное срабатывание интервала, устойчивость
   `repeat`, анимация трея, потеря фазы помодоро.
2. **FixDictationCore** (Rust): остановка записи, выгрузка модели по таймауту, сохранение
   повтора распознавания, снятие хоткеев при выключении речи.
3. **FixVault**: три блокера потери данных (затирание черновика, перезапись `Untitled.md`,
   сброс активной заметки) и девять пунктов вокруг дерева, переименования, переиндексации.
4. **FixAssistant**: нумерация дней недели, вызов модели по ключу из хранилища, ложные ответы
   («Команда не распознана» после успеха, «Готово» без создания), плюс защита `db.ts` и
   недостающая подписка на пропущенные будильники.
5. **FixPlanning**: локальное время задачи вместо UTC, подписка «Дня», призрачные события
   календаря, висячие связи при удалении, отсутствие сигнала об изменении данных.
6. **FixMediaSettings**: подтверждение перед удалением, синхронизация очистки медиа с базой,
   потеря штрихов рисунка, переключатель периода статистики, недоступная настройка переноса.
7. **FixDictationUi**: живой тест микрофона и уважение настройки индикатора.

## Не делаем

- Проекцию будильников на «День» и календарь (QA отметил это как пробел в возможностях).
- Синхронизацию заметок между устройствами, вложения и граф связей.
- Полный арт-передел экранов: волна про дефекты, а не про вид.

## Риски

| Риск | Ответ |
|---|---|
| Семь исполнителей в одном дереве | Файлы разведены по владельцам; пересечений нет (см. `interfaces.md`) |
| Правка меняет поведение, а тест этого не ловит | На каждый дефект регрессионный тест, падающий до правки |
| Дни недели — сквозной контракт трёх модулей | Заморожено в `interfaces.md` §2: 0 = воскресенье везде |
| Rust-срезы собираются долго | Срезы идут в основном дереве (тёплый `target`), а не в свежих worktree |
