# Manifest: починка цепочки диктовки

Жалоба (дословно): «Ничего не работает, протеструй все у нас должен был полный функционал handy»

| R## | Требование | Цитата |
|---|---|---|
| R01 | Диктовка работает с моделью, найденной у другого приложения | «Ничего не работает» + ранее выбранная `nemotron через хенди` |
| R02 | Отмена диктовки работает без настройки | следствие «ничего не работает»: `Escape` не срабатывал при пустом поле |
| R03 | Отказ системы зарегистрировать клавишу виден, а не молчит | следствие «протеструй все»: молчаливый `let _ =` скрывал причину |
| R04 | Проверить весь функционал Handy против нашего и сказать честно | «протеструй все у нас должен был полный функционал handy» |

## Доказательство

- R01: сквозной прогон через пайплайн на файле пользователя — русский текст распознан дословно.
- R02: тесты обеих сторон: пустое значение → `Escape`, явное сочетание сохраняется.
- R03: событие `stt://hotkey-error` и запись в лог; на этой машине лог пуст — клавиша встала.
- R04: таблица паритета по README Handy, пятнадцать пунктов, все на месте.
