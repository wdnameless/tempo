# Manifest: обнаружение чужих моделей, GGUF и новый выбор моделей

Запрос (дословно): «Также я хочу, чтобы мы автоматически детектили загружены в данный момент модели,
к примеру сейчас у нас загружена nemotron через хенди. Так же я хочу интерфейс выбора моделей такой»
(со двумя скриншотами экрана моделей другого приложения).

| R## | Требование | Цитата |
|---|---|---|
| R01 | Tempo сам находит модели, уже скачанные на машине, включая скачанные другим приложением | «автоматически детектили загружены в данный момент модели» |
| R02 | Найденное можно выбрать и использовать, без повторного скачивания | «сейчас у нас загружена nemotron через хенди» |
| R03 | Чужое показывается как чужое и не удаляется нашей кнопкой | следствие R01: файл принадлежит другой программе |
| R04 | Экран выбора моделей: два раздела (загруженные / доступные), поиск, полосы точности и скорости, чипы языка и streaming, размер, удаление | «интерфейс выбора моделей такой» + скриншоты |
| R05 | Ничего работающего не ломается: свои модели, загрузка, диктовка, запись | закон проекта; проверяется регрессией |

## Доказательство

- R01/R02: прогон каталога на этой машине находит `nemotron-3.5-asr-streaming-0.6b-Q8_0.gguf` в кэше
  HuggingFace с `source=detected`, `origin=Handy`, `deletable=false`; движок распознаёт русскую речь
  из этого файла на месте.
- R03: тест «чужое не удаляется» + кнопки удаления у найденного нет.
- R04: тесты на два раздела, поиск по обоим, полосы, чипы, пометку активной модели.
- R05: полный `check:all` зелёный; живой запуск приложения.
