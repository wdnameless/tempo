# Гайд: сборка, установка и проверка Tempo

Пошагово: как собрать, где взять portable-копию, как проверить автообновление
и что смотреть глазами. Написан под Windows.

## 0. Что уже установлено у вас

У вас стоит **Alarmer 0.3.x**, установленный через установщик. Это важно, потому что:

- **Данные лежат в `%APPDATA%\com.alarmer.smart\alarmer.json`**. При первом запуске
  Tempo переносит оттуда будильники, задачи, заметки и настройки в новую базу.
  Программы-расписания при этом отбрасываются (решение R30) — это ожидаемо.
- **Старый `alarmer.json` не удаляется**: он остаётся вашей резервной копией.
- **Автообновление довезёт вас до Tempo один раз**, дальше уже Tempo обновляет сам себя.
  Причина: установщик сменил идентификатор приложения (`com.alarmer.smart` →
  `app.tempo.desktop`), поэтому Windows видит Tempo как **новую программу**, а не как
  обновление старой. Это записано в решении R32 и проверяется на шаге 6.

## 1. Что нужно установить один раз

| Что | Зачем | Проверка |
|---|---|---|
| **Rust** (rustup, toolchain stable) | сборка бэкенда | `cargo --version` |
| **Bun** | фронтенд и скрипты | `bun --version` |
| **WebView2** | уже есть в Windows 11 | — |
| **Средства сборки C++** (MSVC) | линковка Rust | ставится вместе с rustup |

Сборка Rust занимает минуты при первом запуске и секунды потом.

## 2. Ветка с работой

Вся работа — в ветке `feat/wave0-foundation`:

```bash
cd D:/WORK/Alarmer
git checkout feat/wave0-foundation
git log --oneline -1          # должен быть коммит про 0.7.0
```

`master` намеренно не трогается: там ваша работающая 0.3.3, и переезд стоит делать
одним осознанным действием, а не по частям.

## 3. Проверка перед сборкой (быстро, без запуска приложения)

```bash
bun run check:all
```

Ожидаемо: `tsc` без ошибок, eslint без замечаний, **295 тестов** vitest,
**77 тестов** cargo, покрытие выше порогов. Если что-то красное — не собирайте,
присылайте вывод.

## 4. Сборка

```bash
bun run tauri build --no-bundle
```

**Почему `--no-bundle`:** полная сборка подписывает артефакты обновления и требует
приватный ключ, который лежит в GitHub Secrets и на машине его нет:

```
Error A public key has been found, but no private key.
      Make sure to set `TAURI_SIGNING_PRIVATE_KEY` environment variable.
```

`--no-bundle` собирает приложение и не пытается подписать — этого достаточно для
проверки. Полная сборка с установщиком нужна только для релиза, и её делает CI
(там ключ есть).

Если всё же нужен установщик локально:

```bash
set TAURI_SIGNING_PRIVATE_KEY=<ваш ключ>
bun run tauri build
```

Куда смотреть результат:

| Что | Где |
|---|---|
| Установщик | `src-tauri/target/release/bundle/nsis/Tempo_0.7.0_x64-setup.exe` |
| MSI | `src-tauri/target/release/bundle/msi/` |
| **Голый exe** | `src-tauri/target/release/tempo.exe` |

## 5. Portable-копия (безопасный способ всё посмотреть)

Не трогает ни реестр, ни установленную версию — можно запускать рядом со старой.
**Именно так проверена миграция ваших данных.**

```bash
mkdir -p D:/Tempo-portable/data
cp src-tauri/target/release/tempo.exe D:/Tempo-portable/
type nul > D:/Tempo-portable/portable     # маркер: данные рядом с exe
cp "$APPDATA/com.alarmer.smart/alarmer.json" D:/Tempo-portable/data/
```

Запуск из проводника (двойной клик по `tempo.exe`) надёжнее, чем из bash.

Ключевое: **маркер `portable`**. С ним Tempo держит всё в `data\` рядом с собой,
без него — в `%APPDATA%\app.tempo.desktop\`.

Ожидаемо: рядом появится `data\tempo.db`, а в нём — ваши данные. Что именно
переносится (проверено на вашем файле от 0.3):

| Что | Откуда | Куда |
|---|---|---|
| Сообщения копилота | `state.chatMessages` | таблица `chat_messages` |
| Настройки | `state.preferences` (`alarmer_*`) | `preferences` (`tempo_*`) |
| Настройки ИИ | `state.aiSettings` | `preferences` (`tempo_ai_*`) |
| Настройки интерфейса | `state.dynamicUi` | `preferences` (`tempo_dynamic_ui`) |
| Будильники, задачи, заметки | те же поля | одноимённые таблицы |
| **Программы-расписания** | `state.schedules` | **не переносятся** (решение R30) |
| API-ключ | `state.aiSettings.apiKey` | **не переносится** — ему место в keyring, не в базе |

Проверить содержимое базы, не открывая приложение:

```bash
python -c "import sqlite3;c=sqlite3.connect('D:/Tempo-portable/data/tempo.db');print([r for r in c.execute('SELECT key FROM preferences ORDER BY key')])"
```

## 6. Что проверить глазами

### Фундамент (волна 0)

- [ ] Окно называется **Tempo**, в трее тоже.
- [ ] Слева сайдбар: иконка + подпись, активный пункт подсвечен.
- [ ] Сворачивается кнопкой **и** `⌘S` (Ctrl+S), состояние помнится между запусками.
- [ ] Настройки → Основные: восемь кружков акцента, при клике перекрашивается **весь**
      интерфейс, без перезапуска.
- [ ] Настройки → переключатель EN/RU переводит навигацию целиком.
- [ ] Будильники продолжают звонить: поставьте на ближайшую минуту, сверните в трей.

### Помодоро (волна 1)

- [ ] Главный экран: крупный циферблат, «1 из 4», счётчик за сегодня.
- [ ] Старт → идёт отсчёт, переключатель Помодоро/Стоп-вотч работает.
- [ ] Фон меняет оттенок по фазе и мягко перетекает.
- [ ] Перерыв начинается **сам** по нулю фокуса.
- [ ] Настройки → Помодоро: ползунки 10–120, перерывы, автостарт, звук фокуса.
- [ ] `Alt+S` / `Alt+R` (глобальные) управляют таймером при свёрнутом окне.

### Поиск (волна 2)

- [ ] `⌘K` открывает палитру. Пустой запрос — список команд.
- [ ] Ввод «зад» → «Задачи»; Enter → переход на экран.
- [ ] Начните вводить текст из будильника → он находится.
- [ ] Введите `(`, `"`, `AND` — палитра не падает и показывает «ничего не найдено».

### Задачи и списки (волна 3)

- [ ] Экран «Задачи»: поле сверху, Enter создаёт задачу.
- [ ] Клик по задаче открывает строчное редактирование: срок, время, минуты, приоритет.
- [ ] У задачи можно раскрыть подзадачи и добавить их; виден счётчик `1/2`.
- [ ] Сортировка «Вручную / По сроку / По приоритету» переключается и помнится.
- [ ] Выполненные сворачиваются в группу «Выполненные».
- [ ] Экран «Списки»: создание списка, добавление пунктов, «в задачу» переносит
      пункт из списка в задачи.
- [ ] Введите название задачи в `⌘K` → находится, Enter **прокручивает к строке**
      и подсвечивает её.

## 7. Проверка автообновления (то, ради чего всё разделение сборок)

Проверять нужно **на portable-копии**, потому что она подменяет свой exe, а не
запускает установщик.

1. Убедитесь, что `D:\Tempo-portable\tempo.exe` — это сборка **0.7.0**.
2. Опубликуйте релиз `v0.7.0` (или более новый) — тогда `latest.json` появится по
   адресу `https://github.com/wdnameless/Alarmer/releases/latest/download/latest.json`.
3. Запустите portable-копию → Настройки → проверка обновлений. Ожидаемо: предложение
   обновления, скачивание с прогрессом, подмена файла, перезапуск.
4. После перезапуска версия в настройках — новая.

**Почему репозиторий остался `wdnameless/Alarmer`:** мы не переименовываем GitHub-репозиторий,
поэтому URL манифеста не менялся ни в одном из трёх мест. Если репозиторий когда-нибудь
переименуете — менять надо **все три** синхронно: `portable_update.rs::MANIFEST_URL`,
`tauri.conf.json → plugins.updater.endpoints`, сборка `latest.json` в `release.yml`.

## 8. Переезд на Tempo (когда всё проверено)

1. Закройте Alarmer (в трее тоже).
2. Запустите `Tempo_0.7.0_x64-setup.exe`.
3. Убедитесь, что будильники, задачи и заметки на месте.
4. **Удалите Alarmer** через «Установка и удаление программ» — иначе останутся две
   программы с двумя треями.

Старик `alarmer.json` не удаляйте, пока не убедитесь, что всё перенеслось.

## 9. Если что-то не так

| Симптом | Причина | Что делать |
|---|---|---|
| Пусто после переезда | не нашли `alarmer.json` | проверьте `%APPDATA%\com.alarmer.smart\alarmer.json`; для portable — `data\alarmer.json` рядом с exe |
| Палитра открывается пустой | реестр не заполнился | перезапустите; если повторяется — скажите, это дефект |
| Таймер не идёт в браузере | в `vite dev` нет бэкенда | это нормально, проверяйте в собранном приложении |
| Будильник не звенит | приложение выключено в трее | проверьте `sound\` в настройках и «Аларм включён» |
| Сборка падает на Rust | нет MSVC | доустановите «Desktop development with C++» |
| `A public key has been found, but no private key` | полная сборка без ключа подписи | используйте `--no-bundle` (см. шаг 4) |
| После переезда пусто, хотя файл на месте | миграция не нашла данные | проверьте, что файл лежит либо рядом с exe (`data\`), либо в `%APPDATA%\com.alarmer.smart\` |
