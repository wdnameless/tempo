# Manifest: шумодавы, модели Handy, список моделей

Запрос (дословно): «Добавь всякие шумодавы, и STT должен быть список из локальных моделей которые
есть в handy и интерфейс еще можно доработать»

Ответы на развилки (дословно): шумодав — «RNNoise + DSP + Silero VAD»; модели — «весь набор handy»;
интерфейс — «2» (список моделей в мастере речи).

| R## | Требование | Цитата |
|---|---|---|
| R01 | В тракт микрофона добавляется набор шумодавов с тумблерами: high-pass, шумовой гейт, AGC | «Добавь всякие шумодавы» + «RNNoise + DSP + Silero VAD» |
| R02 | RNNoise (нейросетевой шумодав) — отдельный тумблер, по умолчанию выключен | «RNNoise + DSP + Silero VAD» |
| R03 | Нейросетевой VAD (Silero) как третий бэкенд рядом с energy и earshot | «RNNoise + DSP + Silero VAD» |
| R04 | Список моделей STT включает локальные модели, которые есть в Handy: Parakeet v2/v3, Moonshine ×4, SenseVoice, Canary 180M/1B, Cohere, GigaAM v3 — сверх whisper-набора | «STT должен быть список из локальных моделей которые есть в handy» + «весь набор handy» |
| R05 | Список моделей в мастере показывает квант, размер и пометку «установлена», сгруппирован по языку и скорости | «интерфейс еще можно доработать» + ответ «2» |
| R06 | Ничего из работающего не ломается: диктовка, запись, выбор устройства, каналы, история, существующие модели | «Never simplify away… anything explicitly requested» — закон проекта; проверяется регрессией |

## Границы (что вне объёма этого среза)

- Модели Handy вне whisper требуют второго движка (ONNX Runtime). Это отдельный срез: сначала
  рантайм и Silero VAD на нём, затем движки по одной. Здесь — R01–R03 и R05; R04 закрывается
  срезами движков, каждый со своей загрузкой и проверкой.

## Доказательство

- R01/R02: `cargo test` по блокам цепочки (high-pass режет низ и пропускает верх; гейт глушит
  тишину и пропускает речь; RNNoise не меняет длину и число каналов; AGC поднимает тихий сигнал),
  `clippy -D warnings`.
- R03: `vad_backend` принимает `silero`, движок грузит модель и решает «речь/не речь» на тестовом
  сигнале; откат на energy, если модель недоступна.
- R04: каталог содержит модели Handy; каждая появляется в списке и скачивается.
- R05: живой экран мастера — квант, размер, пометка установленной, группировка.
- R06: полный `bun run check:all` + `cargo test` зелёные; живая диктовка и запись.
