# Разведка: MVP Hardening & End-to-End Polish

## Текущее состояние кодовой базы

- **Дизайн**: внедрён швейцарский монохромный стиль `trywinter.app` (`#000000`, `--accent: #FFFFFF`, белая типографика, 3D wireframe ambient canvas, плавающие капсулы управления).
- **Бэкенд**: 124 теста Rust, чистый clippy `-D warnings`, rusqlite, cpal, wasapi, windows-capture, transcribe-cpp (Whisper GGUF), журнал синхронизации.
- **Фронтенд**: 528 тестов vitest, 57 файлов, tsc 0 ошибок, eslint 0 предупреждений.

## Точки доводки функционала до боевого уровня (MVP)

1. **Dashboard & Pomodoro**:
   - Плавающая капсула плеера: клик по цифрам таймера открывает минималистичный ряд пресетов (15, 25, 45, 60 мин) с немедленным переводом таймера.
   - Клик по фазе переключает Фокус / Короткий перерыв / Длинный перерыв с моментальной трансляцией бэкенду.
   - Клик по иконке звука открывает селектор Focus Audio (дождь, волны, белый шум, костёр) и ползунок громкости.
2. **Tasks, Day Planning & Calendar**:
   - Быстрое создание задач по `Enter`, редактирование по месту, удобное перемещение в слоты времени таймлайна дня.
   - Календарь: полноценная синхронизация локальных событий и задач со временем, клик по слоту дня/недели создаёт событие на этот час.
3. **Drawings (Холст)**:
   - Живое рисование фигур и стрелок (drag-to-draw с превью контура во время перетаскивания).
   - История правок: отмена (`Ctrl+Z`) и повтор (`Ctrl+Y` / `Ctrl+Shift+Z`).
   - Сохранение превью в список и на диск.
4. **Voice & Dictation (STT)**:
   - Push-to-Talk диктовка: удержание хоткея активирует запись, отпускание расшифровывает через Whisper и впечатывает в активное окно.
5. **Notes & Search**:
   - `[[вики-ссылки]]` и клик для перехода или создания новой заметки.
   - Полнотекстовый поиск ⌘K по всем сущностям (задачи, заметки, рисунки, события, транскрипты записей).
