## Контракты, которые нельзя менять без владельца

- `src/constants/design.ts` + `src/components/ui/**` — владелец Wave 0; цвета только из токенов
- `src/services/db.ts` — **единственная** точка SQL; `EntityMeta` = `id` (UUID v4) + `updated_at` + `deleted_at`
- Слой шорткатов — односложные клавиши НЕ срабатывают в `input`/`textarea`/`contenteditable`
- Реестр источников поиска — волна-владелец регистрирует проекцию своей сущности
- Жизненный цикл медиа — удаление записи удаляет файл; потолок хранилища и очистка
- Бюджеты: фон ≤2% CPU в покое · холст 60 к/с при 500 штрихах · запись экрана ≤15% CPU · поиск ≤100 мс

## Разведка (проверено по исходникам, не по памяти)

- **Handy** (MIT): движки уже опубликованы крейтами — `transcribe-cpp` 0.2.3 (ggml/Vulkan) и
  `transcribe-rs` 0.4.0 (ONNX, CPU); хоткеи `handy-keys` 0.3.4; вставка через Windows `SendInput`
  с сохранением и восстановлением буфера обмена; захват `cpal` 16 кГц + VAD.
  Дефолт Handy — Parakeet EN 0.6B (661 МБ, **только английский**) → для русского берём Whisper.
- **Google**: loopback + PKCE (OOB отключён Google); `calendar.events`/`calendar.readonly` — sensitive,
  верификация требует домена, политики и видео; в статусе Testing refresh-токен живёт **7 дней**;
  `drive.file` — единственный non-sensitive scope для Drive; инкрементальный синк через `syncToken`,
  при `410 Gone` — полная пересинхронизация; вебхуки для desktop недоступны → опрос.
