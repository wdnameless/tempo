# Recon: меню, иконка-песочные часы, анимация в трее

Запрос пользователя (2026-09-22, с приложенным скриншотом бокового блока):

- «это убери» — блок с иконкой часов, надписью `Tempo` и версией в шапке бокового меню
- «AI исситента убери из левого меню»
- «давай улучшим инонку с песочными часами (сделаем его более минималистичной и рукописной)»
- «когда будильник работает пеочные часы должны переворачиваться с анимацией в трее»

## Точки правки (проверены чтением)

| Что | Где | Сейчас |
|---|---|---|
| Блок брендинга в меню | `src/App.tsx:500-510` | иконка `Clock` + `Tempo` + версия из `currentVersion()` |
| Кнопка ассистента в меню | `src/App.tsx:539-548` | кнопка `AI Ассистент` (`Bot`), дублирует правую панель |
| Ассистент вне меню | `src/App.tsx:731` | вертикальная кнопка `AI` у правого края — остаётся, ассистент не теряется |

| Рисованные иконки | `src/components/CustomIcons.tsx:10-20` | `HandHourglass` — уже «рукописный» SVG, используется в `RadialDial.tsx:314` |
| Генератор иконок | `scripts/generateIcons.ts` | одноразовый, через `canvas` (ставится ad hoc: `bun add -d canvas`) |

## Что делаем

1. **Меню**: убрать блок брендинга и кнопку ассистента; правый вертикальный переключатель `AI` остаётся единственным входом к ассистенту.
2. **Иконка**: единый минималистичный рукописный рисунок песочных часов — тонкая линия, чуть неровные штрихи, без заливок и объёма. Применяется и к SVG в интерфейсе, и к иконке приложения/трея.
3. **Анимация в трее**: пока звенит будильник, песочные часы **переворачиваются** — плавный поворот на 180° за такт, повторяется, пока звонок не остановлен; вне звонка иконка статична. Кадры рисуются в Rust (RGBA) и подменяются через `tray.set_icon(...)`, без внешних файлов и зависимостей.

## Проверка приёмки

1. `bun run check` — tsc/eslint/vitest, тесты обновлены (меню без брендинга и без кнопки ассистента; правый переключатель на месте).
2. `cargo test` + `cargo clippy --all-targets -- -D warnings` — тесты рендера кадров: кадр 0° и кадр 180° различаются, картинка заданного размера, поворот меняет пиксели предсказуемо, вне звонка кадр статичен.
3. В собранном приложении: меню без лишнего, ассистент открывается правой кнопкой; при звонке будильника иконка в трее переворачивается, после остановки — статична.
