# Recon: красивый песок со звуком, починка чата

Запрос (2026-09-23, со скриншотом чата): «песок должен красиво пересыпаться, и должен быть звук
переворачивания часов. Так же пофикс ИИ чат, таймстемпы слишком детальные и плохо выглядят,
чат нельзя растягивать, нет кнопки создать новый чат, нет выбора моделей».

## Песок и звук

| Что | Где | Сейчас |
|---|---|---|
| Песок | `src/components/WinterCanvas.tsx` | уровень песка есть (чистая функция), но выглядит как приглушённая заливка; нет струи, нет «горки» в нижней колбе |
| Переворот | там же | по опустошению песка, цикл 60 с |
| Звук | `src/services/sound.ts` (`soundService`) | есть `playUiClick`, `playBeep`, `playCountdownTick`, `speak` — отдельного звука переворота нет |

## Чат

| Что | Где | Сейчас |
|---|---|---|
| Таймстемпы | `src/components/AIChatDrawer.tsx` | печатается сырой ISO: `2026-09-22T07:53:50.092992200+00:00` |
| Размер панели | `AIChatDrawer.tsx` | **логики изменения размера нет вообще**; ручки `ResizeHandles.tsx` в DOM двигают окно приложения, а не чат |
| Новый чат | `AIChatDrawer.tsx`, `src/App.tsx`, `src/services/store.ts` | есть только «Очистить» (`onResetChat`); **сессий нет** — одна лента в `chat_messages` |
| Выбор модели | `src/services/aiGateway.ts` (`baseUrl`, `model`), преф `tempo_ai_model` | модель задаётся только в Настройках; в чате её не видно и не сменить |
| Хранение | `chat_messages` + `store.ts` (`chatRepo`, `chatMessages`) | строки без разделения на разговоры |

## Что делаем

1. **Песок красивее**: видимая струя в горловине, «горка» в нижней колбе, мягкая кромка уровня,
   лёгкое мерцание крупинок — в том же приглушённом языке, но так, чтобы пересыпание читалось.
2. **Звук переворота**: короткий мягкий сигнал в момент, когда часы переворачиваются; играет через
   существующий звуковой сервис, не блокирует кадр, не играет при остановленном таймере.
3. **Чат**: человеческие таймстемпы (время, «вчера»/дата для старых), растягивание панели за край
   с сохранением размера, кнопка «Новый чат» с разделением разговоров по сессиям и списком
   недавних, выбор модели прямо в чате с записью в `tempo_ai_model`.

## Проверка приёмки

1. `bun run check` — tsc/eslint/vitest зелёные, тесты обновлены/добавлены.
2. Живой прогон: песок виден и сыпется, звук слышен при перевороте, таймстемпы читаемые, панель
   тянется, новый чат создаётся, модель выбирается.
