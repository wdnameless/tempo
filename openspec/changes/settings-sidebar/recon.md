# Recon: настройки — левая колонка под-разделов

Запрос: «Продолжай» — продолжить с оставшегося пункта списка улучшений:
«список под-разделов внутри «Настроек» (левая колонка как в macOS) — «Основные» уже длинная».

## Что есть сейчас

`src/components/SettingsView.tsx`, 1815 строк:

| Место | Что там |
|---|---|
| 102-109 | `SECTION_DEFS` — шесть разделов: Основные, ИИ, Интеграции, Речь, Горячие клавиши, О приложении |
| 564-593 | Горизонтальная полоса табов (`role="tablist"`, `overflow-x-auto`, `role="tab"`, `aria-selected`, `aria-controls`) |
| 596-861 | Раздел «Основные» — **264 строки**: три карточки (Таймер и фокус, Переход дня, Медиа) |
| 862-1086 | «ИИ» — 224 строки |
| 1087-1140 | «Интеграции» — 53 |
| 1141-1152 | «Речь» — 11 |
| 1153-1258 | «Горячие клавиши» — 105 |
| 1259-1815 | «О приложении» — 556 |

Карточки внутри разделов помечены `<h2>`: у «Основных» их три (605, 757, 814).

## Решение

Как в macOS: разделы переезжают из горизонтальной полосы в **левую колонку**, а у длинных
разделов под активным пунктом появляются **под-пункты**, которые прокручивают панель к нужному
блоку. Горизонтальные табы — это ещё и скролл на узком окне; колонка убирает и это.

## Что считается доказательством

- `bunx vitest run` по тестам настроек: шесть пунктов в колонке, активный помечен,
  под-пункт прокручивает панель к своему блоку, `role="tabpanel"` и `id="section-<id>"` на месте.
- `bunx tsc --noEmit` и `eslint` чисто.
- Живой экран в браузере: колонка, переход между разделами, под-пункты «Основных».
