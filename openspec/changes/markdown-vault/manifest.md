# Manifest: локальное markdown-хранилище и редактор

Дословные цитаты пользователя (2026-09-22 + ответы виджета Wave 0):

- «Я хочу редактор текста как notion, при этом поддержку MD файлов и структуру даты как в obsidian чтобы все хранилось локально в папках и md файлах»
- «editor: Как Obsidian — live-preview поверх markdown»
- «truth: Файлы главные, база — индекс»
- «vault_location: Своя папка на выбор, с дефолтом»
- «date_layout: Journal/2026/09/2026-09-22.md»
- «external_edits: Читать при открытии + кнопка обновить»

| R## | Требование | Источник | Проверка |
|---|---|---|---|
| R01 | Каждая заметка — это `.md` файл на диске; текст заметки читается и пишется в файл, а не только в базу | «все хранилось локально в папках и md файлах» + «файлы главные» | После создания/правки заметки файл существует и содержит тот же markdown; тест на запись/чтение |
| R02 | База — индекс: ссылки `[[...]]`, бэклинки и поиск пересчитываются из файлов и продолжают работать | «база — индекс» | `[[Ссылка]]` даёт бэклинк, поиск находит текст, введённый в файле снаружи после переиндексации |
| R03 | Хранилище — своя папка; по умолчанию внутри данных приложения, но её можно сменить на любую (включая существующее хранилище Obsidian) | «чтобы все хранилось локально в папках» + «своя папка на выбор, с дефолтом» | Настройка «папка заметок» + системный диалог выбора; после смены дерево и заметки берутся из новой папки |
| R04 | Ежедневные заметки раскладываются по датам: `Journal/YYYY/MM/YYYY-MM-DD.md` | «структуру даты как в obsidian» + «Journal/2026/09/2026-09-22.md» | Кнопка «сегодня» создаёт файл ровно по этому пути; повторное нажатие открывает существующий, а не плодит копии |
| R05 | Редактор — live-preview: markdown остаётся текстом, но разметка отображается оформленной (заголовки, жирный, курсив, код, списки, цитаты, чек-боксы) | «редактор текста как notion» + «Как Obsidian — live-preview» | В редакторе видны оформленные элементы, а в файле — чистый markdown; чек-бокс `- [ ]` кликается и меняет файл |
| R06 | Дерево папок и файлов в интерфейсе: создать заметку и папку, переименовать, удалить, открыть | «все хранилось локально в папках» | Дерево показывает реальные папки vault; операции меняют файлы на диске, а не только базу |
| R07 | Автосохранение: набранный текст не теряется при переключении заметки или закрытии | «редактор текста как notion» (там нет кнопки «сохранить») | Дебаунс-запись в файл; тест: правка → переключение заметки → текст на месте |
| R08 | Внешние правки подхватываются по кнопке «Обновить»; ничего не перетирается молча | «Читать при открытии + кнопка обновить» | Правка файла в блокноте → «Обновить» → в редакторе новый текст; если файл изменился, а в редакторе есть несохранённое — показать предупреждение, а не потерять |
| R09 | Существующие заметки не теряются: одноразовая выгрузка из базы в файлы | «все хранилось … в md файлах» | Миграция создаёт файлы для всех заметок; после неё список и содержимое совпадают с прежними |
| R10 | Всё, что уже завязано на заметки, продолжает работать: дашборд, ассистент (`create_note`), поиск, переход из поиска, синхронизация | «доделай мвп сам» (не ломать работающее) | Существующие тесты заметок/поиска/ассистента зелёные; ассистент создаёт заметку, и она появляется как файл |
| R11 | Редактор не воюет с глобальными хоткеями диктовки и не ломает выделение текста | техническое требование | Ввод текста в редакторе не запускает диктовку; выделение мышью работает (в проекте `user-select: none` на `body`) |
| R12 | Никаких «мёртвых» дублей: старый textarea-редактор и переключатель превью удалены, а не оставлены рядом | «доделай мвп сам» | В коде не осталось второго редактора; тесты обновлены под новый |

Отклонения, зафиксированные честно:

| Что | Почему | Потолок | Апгрейд |
|---|---|---|---|
| Живое слежение за папкой (watcher) | Пользователь выбрал чтение при открытии + кнопку | ручное обновление | watcher на `notify`, когда появится потребность |
| Блочный WYSIWYG как в Notion (TipTap) | Выбран live-preview как в Obsidian — ближе к «md-файлы» и без крупной зависимости | markdown + оформление | TipTap поверх тех же файлов, если понадобятся блоки и drag-handle |
| Вложения, теги, граф связей, шаблоны | Не влияет на ядро «заметки в файлах» | нет | отдельные волны |
| Синхронизация заметок между устройствами | Отдельная подсистема | локальные файлы | существующий `sync/` |
