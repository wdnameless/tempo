Жалоба (дословно): «Ничего не работает, протеструй все у нас должен был полный функционал handy».

## Что уже доказано экспериментом

| Факт | Доказательство |
|---|---|
| Выбранная модель — **найденная** (`source=detected`), её нет в каталоге | `catalog::find("nemotron-3.5-asr-streaming-0.6b-Q8_0")` → `None` |
| Путь к файлу находится правильно | `installed_path` → `…\snapshots\…\nemotron-3.5-asr-streaming-0.6b-Q8_0.gguf` |
| **Движок выбирается неверно** | диктовка спросит `whisper` вместо `transcribecpp` — whisper пытается открыть GGUF и падает |
| В настройке отмены пусто | `tempo_speech_cancel_hotkey = ""` — `Escape` не работает |
| Отключение модели | `tempo_speech_model_unload_secs = 0` = «никогда» |

## Замороженное решение

1. **Движок берётся из того же списка, что показывает интерфейс** — из `ModelManager::list()`, а не
   из одного каталога. Каталог остаётся первым источником для своих моделей; для найденных движок
   приходит из их записи. Никаких «угадаю по имени файла».
2. **Пустое сочетание отмены означает `Escape`**, а не «отмены нет»: пользователь, не трогавший поле,
   получает рабочую отмену. Явно заданное сочетание уважается.
3. Полный функциональный прогон — на **вашей** конфигурации: модель Nemotron из кэша Handy,
   `hold_or_toggle`, Silero VAD.
