# Manifest: MVP Hardening & End-to-End Polish

## Исходный бриф и цитаты пользователя
- «Пойдет, но теперь очень все сыро и половина не работает.»
- «Давай составим т3 план по мвп, чтобы продуктом уже можно было пользоваться покроем интерфейс фунционалом»
- Ответы в Wave 0 Grilling:
  - `mvp_scope_focus`: «Сквозная полировка всех экранов и связок»
  - `dashboard_experience`: «Быстрые пресеты при клике на цифры таймера»
  - `drawings_enhancement`: «Фигуры и стрелки перетаскиванием (drag-to-draw) + Ctrl+Z»
  - `stt_dictation_behavior`: «Push-to-Talk (зажал — сказал — отпустил)»

## Требования

| ID | Требование | Якорь / решение |
|---|---|---|
| R101 | Таймер на главном экране: клик по времени открывает ряд быстрых пресетов (15, 25, 45, 60 мин) с мгновенным применением; клик по точке/фазе переключает режим (фокус / перерыв) | Q: «Быстрые пресеты при клике на цифры таймера» |
| R102 | Focus Audio в плавающей панели: клик по иконке звука открывает селектор звуковых ландшафтов (шум дождя, волны, костёр, белый шум) с регулировкой громкости | «покроем интерфейс функционалом» |
| R103 | Задачи и списки: инлайн-создание по Enter, редактирование по месту, смена статуса и приоритета без задержек и перезагрузок | «чтобы продуктом уже можно было пользоваться» |
| R104 | Таймлайн дня и Календарь: 1-клик перенос задач в слоты времени, отображение событий и задач на сетке, быстрое создание события кликом по слоту | «сквозная полировка всех экранов и связок» |
| R105 | Холст рисования: создание фигур (прямоугольник, круг, ромб, стрелка, линия) перетаскиванием мыши с живым превью контура (drag-to-draw) | Q: «Фигуры и стрелки перетаскиванием (drag-to-draw) + Ctrl+Z» |
| R106 | История правок холста: Undo/Redo (`Ctrl+Z`, `Ctrl+Y`) со стеком действий; ластик стирает пересечённые штрихи | Q: «+ Ctrl+Z» |
| R107 | Заметки: клик по вики-ссылке `[[заголовок]]` мгновенно открывает целевую заметку или предлагает создать её, панель обратных ссылок обновляется в реальном времени | «сквозная полировка всех экранов» |
| R108 | Диктовка Push-to-Talk: удержание глобальной горячей клавиши активирует запись микрофона, отпускание расшифровывает через Whisper и вставляет текст через SendInput в активное окно | Q: «Push-to-Talk (зажал — сказал — отпустил)» |
| R109 | Записи: однокликовый старт/стоп записи микрофона и экрана, живой индикатор звука, воспроизведение в карточке с перемоткой | «покроем интерфейс функционалом» |
| R110 | Поиск Cmd+K: сквозной поиск по задачам, заметкам, событиям календаря и расшифровкам записей с навигацией клавиатурой и открытием нужного экрана | «сквозная полировка всех экранов и связок» |
| R111 | Настройки и синхронизация: проверка звука, статус модели Whisper, локальная папка для синхронизации журнала с мгновенным результатом | «чтобы продуктом уже можно было пользоваться» |
