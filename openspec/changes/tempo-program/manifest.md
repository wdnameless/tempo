# Requirements manifest — программа Tempo

Источник: сообщение пользователя от 2026-09-19 (12 пунктов + приложенные скриншоты интерфейса)
и ответы на интервью Wave 0 (27 вопросов в 4 раундах, отвечено на все).
Референс: скриншоты Settings / Integrations / Speech to Text / Shortcuts (шорткаты:
Spotlight ⌘K, Notes N, Drawing D, Stats S, Tasks T, Lists L, Recordings R, Change Background B,
Calendar C, Daily Planning ⌘P, Toggle Sidebar ⌘S, Reset music ⇧R, Settings ?).

Каждый R## наблюдаем: он называет, что пользователь может сделать или увидеть.

## Границы

**В программе**: дизайн-система и каркас · помодоро на главном · динамический фон · поиск Cmd+K ·
задачи · списки · Google Calendar (чтение событий + запись задач) · daily planning · заметки ·
рисунки · записи (аудио/системный звук/экран) · календарь · статистика · настройки ·
speech-to-text · аккаунт Google · синк через личный Google Drive.

**Вне программы**: интеграция с Apple Music (прямое указание) · платежи и подписки · командная
работа и шаринг · мобильные приложения · PWA (отдельная волна **после** этой программы) ·
macOS и Linux сборки (Windows-first).

## Ограничения

- Офлайн-first: приложение полностью работает без интернета; сеть нужна только Google-функциям.
- Portable-режим и автообновление не ломаются (R33).
- Покрытие не падает ниже ratchet: statements ≥53, branches ≥50, functions ≥50, lines ≥54
  (текущее 59.36 / 55.09 / 56.1 / 60.41).
- Никакой новой внешней зависимости без проверки: сначала смотрим, есть ли крейт/пакет, уже
  используемый в проекте.
- Ключи и токены — только в keyring, никогда в БД, в логах или в отчётах.

## Критерии успеха (наблюдаемые)

1. Приложение запускается как `tempo.exe`, данные лежат в `data/tempo.db`, старые будильники на месте,
   программ в интерфейсе нет.
2. Пользователь запускает помодоро на главном экране; после фокуса перерыв стартует сам; фон меняет
   оттенок по фазе.
3. Cmd+K находит задачу по слову из её заголовка, заметку по тексту и запись по транскрипту.
4. Созданная на 14:00 задача появляется событием в Google Calendar; перенесённое в Google событие
   меняет время в Календаре Tempo.
5. Утренний ритуал раскладывает три главные задачи по слотам, вечерний показывает сделанное и
   переносит незавершённое на завтра.
6. Диктовка вставляет распознанный текст в активное окно и восстанавливает буфер обмена.
7. `bun run check:all` зелёный; clippy `-D warnings` чист; автообновление на portable-копии проверено.

## Решения последнего раунда (после независимой проверки плана)

- **R42** — RU/EN сохраняем: новые экраны переводятся на оба языка.
- **R41** — Focus Audio: встроенные наборы генерируются в WebAudio (бурый/белый шум и близкие
  текстуры) плюс уже существующая ссылка на YouTube; лицензионных треков в сборке нет.
- **R32** — имя Tempo подтверждено. **Коллизии имени не проверены**: инструмент веб-поиска
  недоступен без подписки. Технический переименование от публичного имени не зависит и делается
  один раз; публичное имя меняется отдельным рефакторингом строк.
