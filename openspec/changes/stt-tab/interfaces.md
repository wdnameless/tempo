# Interfaces: вкладка STT, настройки и анимация диктовки (заморожено 2026-09-24)

Запрос (дословно): «Сделай отдельную вкалдку в боковом меню STT, И там должны быть настройки моделей
как в handy, горячих клавиш (по дефолту ctrl+s) и когда зажимаешь проигрывается анимация как в handy»
(со скриншотом анимации — лента волн с подсветкой, и экраном моделей Handy).

## Решение по навигации

Отдельный раздел бокового меню **STT** со своими под-разделами (как внутри «Настроек»):

| Под-раздел | Что там |
|---|---|
| Модели | нынешняя библиотека моделей целиком: «Загруженные» / «Доступные», поиск, полосы, чипы, найденное на диске |
| Клавиши | горячая клавиша диктовки и отмены, запись сочетания |
| Анимация | внешний вид индикатора: волна и её поведение |
| Звук | звуковой отклик диктовки |
| Текст | вставка, клипборд, язык и словарь, пост-обработка |
| История | расшифровки |

Настройки речи **уезжают** из «Настроек» в этот раздел: две копии одного экрана не заводим. В «Настройках»
остаётся строка-указатель на новый раздел.

## Замороженный контракт кода

```ts
// src/services/speechSettings.ts — поле уже есть, меняется только значение по умолчанию
hotkey: string;          // по умолчанию 'Ctrl+S' (было пусто)
cancelHotkey: string;    // по умолчанию 'Escape'

// новое поле внешнего вида индикатора
dictationWave: boolean;      // по умолчанию true — волна вместо полоски
dictationWaveBars: number;   // по умолчанию 24 — сколько столбиков в волне
```

```ts
// src/components/DictationIndicator.tsx — публичный интерфейс не меняется
export interface DictationIndicatorProps { variant?: 'pill' | 'overlay'; ... }
```

**Конфликт, разрешаемый в этом же срезе:** `Ctrl+S` сейчас занят — это «Свернуть/развернуть боковую
панель» (`src/services/shortcuts.ts:382`, `keys: ['⌘','S']`, а `⌘` на Windows и есть Ctrl). Две функции
на одной клавише несовместимы: одна из них молча не сработает. Решение: диктовка забирает `Ctrl+S`
(как просил пользователь), панель переезжает на `Ctrl+B`. Обе правки — здесь же, вместе с тестом, что
обе срабатывают и не перехватывают друг друга.

Индикатор обязан оставаться **не забирающим фокус** у прежнего активного окна (это уже так и должно
остаться), и обязан появляться **в момент нажатия клавиши**, а не после начала распознавания.

## Анимация

- Волна из `dictationWaveBars` столбиков, высота — от живого уровня микрофона (`state.level`),
  с подсветкой в цвете темы; выглядит как лента, а не как одна полоска.
- Пока клавиша зажата — волна живёт и реагирует на голос; на отпускании гаснет, а не обрывается.
- Уважает `prefers-reduced-motion`: без движения — статичная форма той же высоты.

- `bunx tsc --noEmit`, `eslint`, `vitest`: раздел STT есть в боковом меню и открывает свои под-разделы;

  и реагирует на уровень; при `prefers-reduced-motion` движения нет.
