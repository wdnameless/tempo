# Tempo

Офлайн-приложение для управления временем: расписания, интервальные блоки,
будильники и статистика фокуса. Tauri 2 + React 19 + Rust.
## Что умеет

- **Расписания как основная сущность.** Вставьте свой план текстом — он станет
  сохранённой программой с шагами, которую можно включить целиком, отредактировать
  и переиспользовать каждый день.
- **Два вида шагов.** Момент времени (звонит будильник) и интервальный блок
  (последовательность упражнений с таймером и голосовыми подсказками).
- **Экран «Сегодня».** Что сейчас и что дальше — вместо простого списка времени.
- **Задачи.** Что именно делать, с привязкой к шагам программы.
- **Итоги.** Серия дней, фокус за неделю, пик продуктивности — из реально
  отработанных сессий.
- **Будильники звонят всегда.** Планировщик живёт в Rust и срабатывает при
  скрытом окне, в трее и без открытого приложения.
- **Таймер переживает всё.** Отсчёт живёт в Rust: смена экрана, скрытие окна и
  горячие клавиши работают одинаково.
- **Голосовое сопровождение.** Нейронные голоса Microsoft Edge Neural TTS.
- **Диктовка с зажатой клавишей.** Зажали клавишу — говорите, отпустили — текст
  вставляется в активное окно. Короткое нажатие фиксирует запись до следующего
  нажатия, `Esc` отменяет. Клавиша записывается с клавиатуры в настройках, режимы —
  «зажать», «переключать» и «оба» (по умолчанию — «оба»).
- **Локальные модели Whisper с выбором кванта.** Каталог из 13 моделей (tiny … large-v3,
  включая `.en`-варианты) по 6 квантов каждая; карточка показывает размер, скорость,
  точность и языки. Скачивание с прогрессом, скоростью и ETA, с докачкой после обрыва,
  проверкой sha256 и зеркалом; можно подложить свой `.gguf` в папку моделей.
- **Распознавание без облака.** VAD (Earshot или энергетический) отсекает тишину до
  отправки в движок, модель живёт в памяти только пока нужна, ускоритель выбирается
  (авто/GPU/CPU). Свой словарь, удаление слов-паразитов, язык и перевод на английский,
  история с аудио и повторным распознаванием, пост-обработка через ИИ-шов.
- **ИИ-ассистент (BYOK).** Любой OpenAI-совместимый провайдер. Ключ хранится
  в системном хранилище учётных данных, а не в файле данных.

## Обновления

Приложение обновляется само, из релизов **этого** репозитория (`wdnameless/Alarmer`). Два пути, потому
что приложение поставляется двумя способами и они не могут использовать один:

| Сборка | Как обновляется |
|---|---|
| **Установленная** | Штатный updater Tauri: проверяет подпись и передаёт управление установщику ОС |
| **Портативная** | Скачивает подписанный portable-архив (`tempo-*-portable-windows.zip`) и подменяет свой файл — установщик не запускается |

Портативная сборка не может использовать штатный путь: на Windows он запускает
NSIS-установщик, который пишет в `Program Files` и реестр — ровно то, чего
портативная копия избегает.

Оба пути читают один `latest.json`, который публикуется на каждом релизе:

```
https://github.com/wdnameless/Alarmer/releases/latest/download/latest.json
```
### Ключ подписи

Подпись обязательна и не может быть отключена: без неё приложение исполняло бы
скачанный бинарник, полагаясь только на TLS, и любой, кто способен отдать наш
URL, мог бы подсунуть произвольный код.

- Приватный ключ лежит в секрете репозитория `TAURI_SIGNING_PRIVATE_KEY`.
- Публичный — в `src-tauri/tauri.conf.json` и продублирован в
  `src-tauri/src/portable_update.rs` (портативный путь проверяет им же).

> **Потеря приватного ключа означает, что новые обновления больше не дойдут до
> уже установленных копий.** Ключ нужно хранить в надёжном месте. Сменить его
> можно только вместе с новой установкой у всех пользователей.

Проверить подпись вручную:

```bash
bunx tauri signer sign file.zip          # подписать
cat file.zip.sig                          # содержимое для поля signature
```

## Команды

```bash
bun install
bun run dev          # только фронтенд в браузере
bun run tauri dev    # приложение целиком

bun run check        # tsc + eslint + vitest
bun run test:rust    # cargo test (планировщик, таймер, звук)
bun run check:all    # всё вместе — то, что гоняет CI
```

## Сборка и portable-режим

```bash
bun run tauri build              # установщики для текущей ОС
bun run tauri build --no-bundle  # только бинарник
```

**Portable-режим** включается сам, если рядом с исполняемым файлом есть файл
`portable` (или задана переменная окружения `ALARMER_PORTABLE`). Тогда данные
пишутся в папку `data` рядом с программой, а не в системный профиль
пользователя — приложение можно носить на флешке.

```text
tempo/             <- распакованный portable-архив
├── tempo.exe
├── portable       <- маркер: включает portable-режим
└── data/          <- создаётся при первом запуске
    └── tempo.db
```

Релизы собираются по тегу `v*`: `.github/workflows/release.yml` собирает
Windows-релиз, прикладывая установщик и portable-архив `tempo-v<tag>-portable-windows.zip`.

## Заметки

Заметка пишется в небольшом подмножестве Markdown (`#`, `**жирный**`,
`*курсив*`, `- списки`, `> цитаты`, `` `код` ``, `[ссылки](https://…)`) и
отображается форматированно. Рендер строит элементы из текста и никогда не
вставляет HTML, поэтому заметка не может нарушить CSP или выполнить скрипт.

Заметка может стоять сама по себе, висеть **на будильнике** (показывается на
экране звонка) или **на шаге программы** (показывается в плеере интервалов).


## Архитектура

Владельцем времени является backend, а не UI.

| Rust (`src-tauri/src/`) | Отвечает за |
|---|---|
| `scheduler.rs` | Когда звонить: повторы, snooze, догон пропущенного |
| `timer.rs` | Отсчёт: обратный ход, режим потока, пауза |
| `alarm_sound.rs` | Звук будильника, когда окно скрыто и проигрывать некому |
| `ai.rs` | Запросы к модели — из backend, чтобы работал любой Base URL |
| `credentials.rs` | API-ключ в системном хранилище |
| `lib.rs` | Команды IPC, трей, горячие клавиши |
| `stt/` | Диктовка: автомат активации (`ptt.rs`), хоткеи (`shortcuts.rs`), захват и VAD (`capture.rs`, `vad.rs`), каталог и загрузчик моделей (`catalog.rs`, `models.rs`), движок (`engine.rs`, `accel.rs`), вставка текста (`dictation.rs`), история, звуки, пост-обработка |

| TypeScript (`src/`) | Отвечает за |
|---|---|
| `services/scheduleEngine.ts` | Шов между расписаниями и планировщиком |
| `services/stats.ts` | Производные метрики из журнала сессий |
| `services/session.ts` | Правила учёта фокуса |
| `services/markdown.tsx` | Безопасный рендер заметок (никогда не HTML) |
| `components/AlarmCenter.tsx` | Единственное место, где приложение звонит |
| `services/stt.ts`, `services/sttEvents.ts` | Типизированные команды диктовки и подписка на события движка |
| `components/speech/` | Настройки диктовки: библиотека моделей, режимы, аудио, вставка, звуки, словарь, история, пост-обработка, онбординг |

Полный разбор решений — в `openspec/changes/`.
