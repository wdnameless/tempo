# Interfaces: Ctrl+Space, читаемый тумблер, узкий сайдбар, воздух (2026-09-24)

Запрос (дословно): «Сделаю чтобы можно было использовать ctrl+space, пофикси кнопку enable speech to
text (не потяно что она нажата) Сделай сайдбар меню меньше, сейчас они слишком много места занимают.
и я хочу такой стиль окон, оставлять пространства» (со скриншотом экрана STT и скриншотом Obsidian как
образцом стиля).

## Три подтверждённые причины

1. **Горячая клавиша.** `src/components/speech/HotkeyRecorder.tsx:100-130`: на `keydown` список клавиш
   собирается в состояние React, а на `keyup` берётся из него же. Пока состояние не перерисовалось,
   в `currentKeys` лежит только модификатор — и на проверку уходит строка `Ctrl`, которую бэкенд
   отклоняет (`Invalid accelerator 'Ctrl': must include a non-modifier key`). С `Space` это видно
   отчётливо, потому что `Space` приходит и уходит быстрее остальных.
2. **Тумблер.** `src/components/ui/Toggle.tsx:37-44`: включённое состояние — дорожка `var(--accent)`,
   кружок `var(--text)`. В теме пользователя `--accent: #FFFFFF` и `--text` тоже белый: белое на белом,
   состояние не читается.
3. **Плотность.** Сайдбар `w-52`, колонка под-разделов `w-60`, карточки с `p-4`/`space-y-6` — тесно
   по сравнению с образцом.

## Замороженный контракт

```ts
// Toggle: поведение не меняется, меняется только читаемость состояния
//  - включён: дорожка accent, кружок accent-fg (контрастен к дорожке в любой теме)
//  - выключен: дорожка elevated, кружок text-muted, у дорожки видимая обводка
//  - role="switch" и aria-checked остаются как есть
export interface ToggleProps { checked: boolean; onChange: (c: boolean) => void; disabled?: boolean }
```

```ts
// HotkeyRecorder: набор клавиш хранится в ref, а не в состоянии React,
//  поэтому отпускание любой клавиши видит актуальный набор.
//  Ctrl+Space, Alt+Space, Shift+Space обязаны приниматься.
```

Плотность (значения заморожены):

| Место | Было | Стало |
|---|---|---|
| Боковое меню, развёрнутое | `w-52` | `w-44` |
| Боковое меню, свёрнутое | `w-14` | `w-12` |

| Скругление поверхностей | `rounded-lg` | `rounded-xl` |
